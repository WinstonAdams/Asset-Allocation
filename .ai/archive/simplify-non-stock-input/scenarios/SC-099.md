# SC-099: 保險錄入框帶入當月既有值，無紀錄時必填欄留空

## 行為
- **GIVEN** 「海外年金保單」2026-05 已存紀錄：累計已繳保費 620000、解約金 580000、本月領回金額 0
- **WHEN** 使用者在月度錄入頁選取該項目、月份 2026-05
- **THEN** 累計已繳保費欄帶入 620000、解約金欄帶入 580000、領回金額欄帶入 0
- **WHEN** 使用者不修改任何欄位直接存檔
- **THEN** 該筆紀錄維持原值不變
- **WHEN** 使用者切換到月份 2026-06（該項目當月尚無紀錄）
- **THEN** 累計已繳保費欄、解約金欄留空（必填），領回金額預設 0
- **WHEN** 使用者在累計保費或解約金留空的狀態下直接存檔
- **THEN** 拒絕存檔並提示必填

## 邊界
- 該月已有紀錄但累計保費或解約金為空白時，帶入空白而非 0
