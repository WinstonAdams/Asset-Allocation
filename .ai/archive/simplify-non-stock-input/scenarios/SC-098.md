# SC-098: 修改或刪除保險某月紀錄後，只有後續新方式紀錄的推算淨投入重算，舊方式紀錄維持原值

## 行為
- **GIVEN** 項目「終身壽險」（分類：保險）初始成本 400000，已用新方式連續記錄三個月：2026-05 累計保費 420000（淨投入 20000）、2026-06 累計保費 440000（淨投入 20000）、2026-07 累計保費 460000（淨投入 20000），領回皆為 0
- **WHEN** 使用者把 2026-05 累計保費改成 430000 並存檔
- **THEN** 2026-05 淨投入重算為 (430000 − 400000) − 0 = 30000
- **AND** 2026-06 淨投入跟著重算為 (440000 − 430000) − 0 = 10000
- **AND** 2026-07 淨投入維持 20000 不變
- **AND** 變動的紀錄在同一次存檔中一起生效
- **WHEN**（另一情境，從原始三筆出發）使用者刪除 2026-06 這筆紀錄
- **THEN** 2026-07 的前期累計保費改取 2026-05 的 420000，淨投入重算為 (460000 − 420000) − 0 = 40000

## 邊界
- 被修改月份之後若有本功能上線前的舊方式紀錄（未填累計保費），該舊紀錄維持原手填淨投入不更新；其後第一筆新方式紀錄的前期累計保費改以估算規則涵蓋被改的月份，並正確重算（規則同 SC-078 的股票/ETF 情形）

## 決議
- 已確認（採推薦值）：保險舊紀錄沒有累計保費、無法重算，維持原值不更新；BR-7「舊紀錄也更新」實際只適用活存/定存。
