# SC-095: 保險改填累計已繳保費、解約金與本月領回金額，推算當月淨投入

## 行為
- **GIVEN** 項目「海外年金保單」（分類：保險）2026-04 已用新方式填累計已繳保費 600000
- **WHEN** 使用者在 2026-05 填累計已繳保費 620000、解約金 580000、本月領回金額 0（預設）
- **THEN** 以 2026-04 的累計保費 600000 作為前期累計保費
- **AND** 推算本月淨投入 = (620000 − 600000) − 0 = +20000
- **AND** 存檔前畫面顯示前期累計保費 600000 與推算淨投入 20000 供使用者核對
- **AND** 存檔後 2026-05 紀錄落地：解約金 580000（作為市值）、淨投入 20000
- **AND** 該月報酬由解約金變動扣除淨投入得出
- **WHEN** 使用者在 2026-06 填累計已繳保費 620000、解約金 585000、本月領回金額 30000（生存金）
- **THEN** 推算淨投入 = (620000 − 620000) − 30000 = −30000

## 邊界
- 保險尚無任何新方式紀錄且初始成本 500000：前期累計保費取初始成本，填累計保費 520000、領回 0 → 推算淨投入 +20000
- 解約月份：累計保費照填 620000、解約金填 0、領回填實收 560000 → 推算淨投入 = (620000 − 620000) − 560000 = −560000，解約金 0 為出清語意（見 SC-009）
- 領回金額預設為 0
