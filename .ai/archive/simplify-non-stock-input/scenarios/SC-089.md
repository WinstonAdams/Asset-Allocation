# SC-089: 月度錄入頁顯示本月已存紀錄表格並提醒金額未填項目

## 行為
- **GIVEN** 2026-06 已有四筆紀錄：「活存」餘額 370000；「信用卡」（負債）應繳金額 30000；「房貸」（負債）金額留空未填；「聯發科」（台股/台股ETF）總成本 0、現值 0、已實現收益（合計）50000
- **WHEN** 使用者在月度錄入頁選擇月份 2026-06
- **THEN** 畫面顯示該月所有已存紀錄的唯讀表格，逐列顯示項目名稱、金額、淨投入
- **AND** 資產（「活存」「聯發科」）的金額顯示在「市值 / 餘額」欄；負債（「信用卡」「房貸」）的金額顯示在「應繳金額」欄（見 SC-101）
- **AND** 股票/ETF 與保險項目另顯示「總成本 / 累計保費」與「已實現收益 / 領回」（合計一欄，不拆成已實現損益與現金股利兩欄）
- **AND** 「房貸」那一列因金額留空，顯示「本月應繳金額尚未填」提醒
- **AND** 「活存」「聯發科」兩列金額已填，不顯示提醒
- **WHEN** 使用者接著存檔補上「房貸」當月應繳金額
- **THEN** 表格立即反映最新的已存紀錄內容，不需離開頁面或重新整理

## 邊界
- 提醒判斷只看金額欄位是否留空，不分項目分類；資產列留空時提醒為「本月市值尚未填」
- 當月完全沒有任何已存紀錄時，表格顯示空狀態，不顯示任何提醒
