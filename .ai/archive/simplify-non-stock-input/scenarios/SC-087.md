# SC-087: 活存/定存與負債的月度錄入框帶入當月既有的單一金額

## 行為
- **GIVEN** 「活存」2026-05 已有紀錄：餘額 350000、淨投入 −150000；「信用卡」（負債）2026-05 應繳金額 30000
- **WHEN** 使用者在月度錄入頁選取項目「活存」、月份 2026-05
- **THEN** 只有「餘額」一欄，預先帶入 350000，沒有淨投入欄
- **WHEN** 使用者不修改任何欄位直接存檔
- **THEN** 該筆紀錄維持餘額 350000、淨投入 −150000 不變（不會被存成預設值而洗掉既有資料）
- **WHEN** 使用者接著切換到項目「定存」、月份 2026-05（「定存」當月尚無紀錄）
- **THEN** 餘額欄留空（必填，不帶 0）
- **WHEN** 使用者在餘額欄留空的狀態下直接存檔
- **THEN** 拒絕存檔並提示餘額必填（避免沒改就把餘額存成 0）
- **WHEN** 使用者選取負債項目「信用卡」、月份 2026-05
- **THEN** 只有「應繳金額」一欄，預先帶入 30000

## 邊界
- 該月已有紀錄但金額欄位是空白（NULL）時，帶入空白而非 0，避免使用者誤以為是 0 並直接存檔
- 該月無紀錄時金額欄留空（必填）
