# SC-082: 金額欄輸入無法解析或留空時拒絕存檔且不落庫

## 行為
- **GIVEN** 使用者在金額欄位輸入 "1,00,000"（分組不是標準三位一組）
- **WHEN** 嘗試存檔
- **THEN** 系統拒絕存檔，提示該欄位輸入無效（訊息帶欄位名稱），不落入資料庫
- **WHEN** 改成輸入純文字 "abc"
- **THEN** 同樣拒絕存檔並提示輸入無效
- **WHEN** 把該欄位清空為空字串後嘗試存檔
- **THEN** 同樣拒絕存檔並提示輸入無效，即使該欄位（例如已實現收益）預設值原本是 0

## 邊界
- 已實現收益欄若使用者從未變動、仍是系統預設值 "0"，視為合法輸入 0，可正常存檔；只有使用者主動清空為空字串才會被拒絕
