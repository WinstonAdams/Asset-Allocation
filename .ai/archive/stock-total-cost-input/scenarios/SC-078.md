# SC-078: 連動重算跨越本功能上線前的紀錄時，影響範圍延伸到更後面的新方式紀錄

## 行為
- **GIVEN** 項目「台達電」（分類：台股/台股ETF）初始成本 300000
- **AND** 2026-01、2026-02 是本功能上線前建立的紀錄（淨投入分別為 10000、15000，皆未填總成本）
- **AND** 2026-03 是第一筆新方式紀錄：總成本 340000、已實現收益 0，前期總成本以過渡規則估算為 300000＋10000＋15000＝325000，推算淨投入 15000
- **WHEN** 使用者刪除 2026-01 這筆紀錄
- **THEN** 2026-02（緊接的下一筆，但仍是本功能上線前建立的紀錄）維持原值，不被重算
- **AND** 2026-03（更後面第一筆用新方式輸入的紀錄）的前期總成本改為 300000＋15000（只剩 2026-02）＝315000，淨投入重算為 (340000 − 315000) − 0 = 25000
- **AND** 這次真正受影響的是 2026-03 而非緊接的 2026-02，代表重算範圍需要往後掃描到第一筆用新方式輸入的紀錄，不能只看緊接的下一筆
