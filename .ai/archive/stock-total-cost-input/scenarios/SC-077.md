# SC-077: 修改或刪除股票/ETF某月紀錄後，下一筆新方式紀錄的推算淨投入自動重算

## 行為
- **GIVEN** 項目「中華電」（分類：台股/台股ETF）初始成本 300000，已用新方式連續記錄三個月：
  2026-05 總成本 350000（淨投入 50000）、2026-06 總成本 400000（淨投入 50000）、2026-07 總成本 420000（淨投入 20000）
- **WHEN** 使用者把 2026-05 的總成本改成 360000（其餘不變）並重新存檔
- **THEN** 2026-05 淨投入重算為 (360000 − 300000) − 0 = 60000
- **AND** 緊接的下一筆 2026-06 淨投入跟著重算為 (400000 − 360000) − 0 = 40000（因為前期總成本變動）
- **AND** 2026-07 淨投入維持 20000 不變（只有緊接的下一筆受影響）
- **WHEN**（另一情境，從原始未修改的三筆紀錄出發）使用者刪除 2026-06 這筆紀錄
- **THEN** 2026-07 的前期總成本改取 2026-05 的總成本 350000（因為 2026-06 已不存在），淨投入重算為 (420000 − 350000) − 0 = 70000
- **AND** 2026-05 紀錄不受影響
