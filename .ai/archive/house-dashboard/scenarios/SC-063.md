# SC-063: bucket 進度：目標金額、缺口、進度百分比與每年需累積速率

## 行為
- **GIVEN** bucket = 1,000,000 元、目標總價 5,000,000 元、自備比率 30%、當年 2026、目標購屋年份 2028
- **WHEN** 檢視 bucket 進度
- **THEN** 目標金額 = 5,000,000 × 30% = 1,500,000 元；缺口 = 500,000 元；進度 ≈ 66.7%；剩餘年數 = 2；每年需累積 = 500,000 ÷ 2 = 250,000 元（BR-2／BR-6）

## 邊界
- bucket 超過目標（如 1,600,000 ≥ 1,500,000）時：缺口 = 0（不為負值）；進度呈現實際值 ≈ 106.7%，不封頂 100%（使用者已定案）
- 剩餘年數 = 1（目標年為明年）時：每年需累積 = 缺口全額
- 進度百分比以目標金額為分母：bucket 1,500,000 → 恰為 100%
