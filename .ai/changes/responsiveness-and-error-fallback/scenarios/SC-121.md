# SC-121: 月度錄入存檔或刪除成功後整頁更新，表格與提示同步

## 行為
- **GIVEN** 使用者在月度錄入頁編輯 2026-09 某項目
- **WHEN** 使用者按「儲存此列」且儲存成功
- **THEN** 整頁重跑，本月已存紀錄表格顯示新值，並顯示存檔成功提示
- **AND** 刪除成功時同理，該列從表格消失
- **AND** 存檔那一次的量測紀錄標示被中斷（interrupted=true），接著的整頁重跑另記一行
