# SC-091: 現金股利填負數時存檔前即遭拒絕

## 行為
- **GIVEN** 使用者在股票/ETF錄入區塊為項目「日月光」2026-06 輸入總成本 0、現值 0、本月已實現損益 100000、本月現金股利 −1000
- **WHEN** 畫面即時預覽推算的淨投入（尚未按存檔）
- **THEN** 系統拒絕該推算，預覽區直接顯示拒絕原因（例如「現金股利不可為負」），不同於「欄位還沒填完」時顯示的佔位提示
- **WHEN** 使用者嘗試存檔
- **THEN** 存檔同樣被拒絕，不落入資料庫

## 邊界
- 已實現損益欄可輸入負值（認列虧損），同一情境下不受此規則限制而被拒絕
- 現金股利恰為 0 時視為合法輸入（非負的邊界值可通過）
