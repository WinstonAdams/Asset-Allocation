# SC-087: 一般分類月度錄入框帶入當月既有值

## 行為
- **GIVEN** 「活存」2026-05 已有紀錄：市值 350000、淨投入 −150000
- **WHEN** 使用者在月度錄入頁選取項目「活存」、月份 2026-05
- **THEN** 市值欄預先帶入 350000、淨投入欄預先帶入 −150000（不是現行預設的空白與 0）
- **WHEN** 使用者不修改任何欄位直接存檔
- **THEN** 該筆紀錄維持市值 350000、淨投入 −150000 不變（不會被存成預設值而洗掉既有資料）
- **WHEN** 使用者接著切換到項目「定存」、月份 2026-05（「定存」當月尚無紀錄）
- **THEN** 市值欄恢復留空、淨投入欄恢復預設 0（該月無紀錄時的現行預設）

## 邊界
- 該月已有紀錄但市值欄位是空白（NULL）時，帶入空白而非 0，避免使用者誤以為是 0 並直接存檔，把空白意外存成 0
- 該月無紀錄時維持現行預設（市值留空、淨投入 0）
