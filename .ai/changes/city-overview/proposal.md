# 城市總覽（city-overview）

## 背景動機

總覽頁目前是數字卡與圖表，要讀完才知道「離目標還有多遠」。使用者希望把月結後的資產狀態畫成一座等角城市，一眼看出目標進度：

- 建築高度＝持有項目市值
- 分區街段＝資產類別
- 天氣＝大跌協定等級
- 購屋工地＝自備款 bucket 進度
- 工地前的五根旗桿＝五條購屋觸發條件
- 負債畫成地面坑洞

設計護欄（2026-10-25 定）：
- 只在月結時變，沒有即時行情。
- 不做分數。
- 主視覺是目標進度，不邀請調整配置的行為。

技術試做已完成（本機分支 `spike/city-overview`，結論複製於本目錄 `spike-findings.md`）：
- Streamlit 1.66.1 Components v2 inline 元件可行。
- 經六輪目視迭代，版位定案為「沿街長條街廓」。

## 目標

- **放置位置**：城市放在總覽頁最上方，當主視覺；現有數字卡與圖表移到城市下方，同時作為文字替代。
- **時間範圍**：預設顯示最新月結，可用月份滑桿回看歷史月份，建築高度平滑過渡。
- **點擊**：
  - 點建築，在城市下方顯示小卡：名稱、類別、該月市值、與前一月相比的變化。
  - 點工地，小卡顯示自備款進度與五條購屋條件各自的狀態。
  - 不跳頁。
- **購屋用途的持有項目只畫進工地**：不另外蓋成建築，金額全部反映在工地的自備款進度，避免同一筆錢畫兩次（與 D14「bucket 不是投資配置」一致）。
- **歷史月份的版位**：版位依「曾經有過的所有項目」排一次，每個月位置不動；當月不存在的項目畫成空地，名稱牌變淡。
- **歷史月份的工地與旗桿**：能逐月算的就算——自備款進度用當月購屋項目金額；依賴目前設定的條件（例如收入門檻、利率參數）用目前設定判定，小卡註明「依目前設定判定」。設計階段逐條確認哪些算得出來。
- **ROADMAP**：在第 4 節插入獨立條目「城市總覽」，不改 Change 1–4 編號。條目寫明它是既有決策的呈現層：把第 1 節的核心問題（軌跡撐不撐得起目標年購屋）畫成一眼可見的進度，對應如下；不新增任何決策、計算或分數，只在月結時變。
  - 工地＝自備款 bucket
  - 旗桿＝五條觸發條件（Change 1）
  - 天氣＝大跌協定等級

## 範圍界定

### 本次做

- 城市元件正式化：Python payload 與版位純函式，加上 JS 與 CSS，放在 `src/asset_lab/` 下的獨立子套件。
- 資料組裝，接既有服務：
  - 市值與歷史最高市值
  - 類別
  - 協定等級
  - 購屋 bucket 進度
  - 五條觸發條件
  - 配置偏離警示
- 歷史月份的資料組裝：逐月市值、逐月協定等級、逐月自備款進度。
- 總覽頁改版：城市在最上方，月份滑桿與點擊小卡在城市下方，原有數字卡與圖表移到後面。
- 天氣名稱與文案常數。
- `streamlit` 版本下限調高到支援 Components v2 的版本，確認打包與 Community Cloud 可跑。
- ROADMAP 第 4 節補「城市總覽」條目（與 1-1 一起 commit）。

### 本次不做

- 自動播放時間軸（只做手動拖月份滑桿）。
- 觸控裝置的滑過提示（手機只保證點擊可用）。
- 從城市直接編輯資料（城市只呈現）。
- D14 的配置偏離排除（屬 ROADMAP Change 2）；偏離警示沿用現行 `compute_drift`。
- 自訂 `[theme]` 主題調整。
- PixiJS 與外部美術素材：本次維持試做的純 Canvas 2D 自繪；美術升級另開 Change，只換畫法。

## 成功標準

1. **總覽頁最上方顯示城市**，用正式庫的月結資料畫出以下元素，使用者目視確認對應正確：
   - 建築：非購屋用途的持有項目，高度＝市值。
   - 坑洞：負債。
   - 工地：自備款進度。
   - 五根旗桿：購屋觸發條件。
   - 天氣：協定等級。
   - 名稱牌上的偏離警示三角。
2. **月份滑桿**：可以回看歷史月份；版位逐月固定，當月不存在的項目畫成空地。
3. **點擊**：點建築或工地，城市下方顯示對應小卡。
4. **版位條件由單元測試保證**：
   - 1280 寬時名稱牌不擋建築、彼此不重疊。
   - 地圖完整落在畫布內。
   - 30 棟的版位計算在 50ms 內。
5. **效能**：
   - 總覽頁切頁耗時中位數比本 Change 前增加不超過 100ms，用重跑量測 log 比對。
   - 拖月份滑桿只重跑城市區塊，不重跑整頁。
6. **部署**：`streamlit` 版本下限調高後，Community Cloud 部署成功，城市正常顯示（使用者目視）。
7. **測試與檢查**：
   - 全套 pytest、ruff、scenario-lint 通過。
   - AppTest 煙霧測試確認總覽頁掛上元件且沒有例外。

## 外部依賴與接口契約

- Streamlit Components v2：`st.components.v2.component(name, html=, css=, js=)`；JS 回傳用 `setTriggerValue`（單次事件）與 `setStateValue`（持久選取）。
- 既有服務（介面以試做 Q8 對照表為準，設計階段核實）：
  - `AllocationService`：快照、持有項目市值趨勢、配置偏離。
  - `ProtocolService.assess`：協定等級與回撤。
  - `HouseService`：bucket 進度、五條觸發條件。
