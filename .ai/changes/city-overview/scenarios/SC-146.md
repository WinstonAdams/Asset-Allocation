# SC-146: 工地前五根旗桿依五條購屋條件顯示達成或半旗

## 行為
- **GIVEN** 五條購屋條件（定錨、收入、自備、月付、認知）中，定錨與認知已達成，收入、自備、月付未達成
- **WHEN** 城市畫工地
- **THEN** 工地正前方有五根旗桿，依固定順序（定錨、收入、自備、月付、認知）排列
- **AND** 達成的兩根旗子升到桿頂，未達成的三根降為半旗
- **AND** 點工地的小卡逐條列出五條條件各自「達成」或「未達成」的狀態

## 邊界
- 旗桿顏色取自城市場景色票，不用 UI 圖示
- 目標總價未設定時：工地進度為 0，小卡顯示「目標未設定」
