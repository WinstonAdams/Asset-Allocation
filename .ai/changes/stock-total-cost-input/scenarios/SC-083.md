# SC-083: 全站金額輸入框放大且僅套用於金額欄

## 行為
- **GIVEN** 使用者進入月度錄入頁或設定頁
- **THEN** 金額欄位（現值/市值、淨投入、總成本、已實現收益、轉移金額、初始市值、初始成本、買房各項金額參數）的輸入框字級與高度明顯放大，比現行版本清楚可辨
- **AND** 同頁的非金額欄位（例如項目名稱、分類、百分比、年份、年限、利率）維持原本大小不變

## 測試對映
- 預期：tests/test_amount_widget.py::test_sc083_*（CSS class 選擇器與樣式字串可用單元測試斷言存在；實際放大後的視覺效果因需經過 app.py 注入樣式，AppTest 單獨跑 views 時不會套用，須在 2-Z 啟動驗證階段人工確認）
