# SC-074: 股票/ETF月度錄入依總成本與前期總成本推算當月淨投入

## 行為
- **GIVEN** 項目「台積電」（分類：台股/台股ETF）初始成本 300000，尚無任何月度紀錄
- **WHEN** 使用者在 2026-05 輸入本月總成本 350000、現值 400000、本月已實現收益 0（預設）
- **THEN** 系統以初始成本 300000 作為前期總成本（尚無前一筆月度紀錄）
- **AND** 推算本月淨投入 = (350000 − 300000) − 0 = 50000
- **AND** 存檔前畫面顯示推算出的本月淨投入 50000 供使用者核對
- **AND** 存檔後 2026-05 紀錄落地：現值 400000、淨投入 50000
- **WHEN** 使用者接著在 2026-06 輸入本月總成本 400000、現值 420000、本月已實現收益 0
- **THEN** 系統以上一筆（2026-05）填的總成本 350000 作為前期總成本
- **AND** 推算本月淨投入 = (400000 − 350000) − 0 = 50000

## 邊界
- 本月已實現收益非零時（例如部分賣出獲利加上領到現金股利）從差額中扣除：延續上例，2026-07 輸入總成本 380000、已實現收益 15000，前期總成本取 2026-06 的 400000，推算淨投入 = (380000 − 400000) − 15000 = −35000（即使當月未清倉，也可能是淨流出）
- 本月已實現收益為負（已實現虧損）時同樣代入公式：同上情境但已實現收益改為 −5000，推算淨投入 = (380000 − 400000) − (−5000) = −15000
- 非台股/台股ETF、美股/美股ETF分類的項目不適用本規則，維持既有「市值/餘額＋當月淨投入」輸入方式
