# SC-075: 過渡期前一筆為本功能上線前建立的紀錄時，前期總成本以初始成本加總淨投入估算並標示

## 行為
- **GIVEN** 項目「鴻海」（分類：台股/台股ETF）初始成本 200000
- **AND** 該項目在本功能上線前已用舊方式記錄了兩個月：2026-02 淨投入 30000、2026-03 淨投入 20000（皆未填總成本）
- **WHEN** 使用者在 2026-04 第一次以新方式輸入本月總成本 280000、現值 290000、本月已實現收益 0
- **THEN** 系統偵測到上一筆有紀錄月份（2026-03）未填總成本，改以「初始成本 200000 ＋ 該月以前所有淨投入（30000＋20000）＝ 250000」估算前期總成本
- **AND** 推算本月淨投入 = (280000 − 250000) − 0 = 30000
- **AND** 存檔前畫面另外標示前期總成本 250000 是用過渡規則估算的，提醒使用者注意可能與券商實際總成本有落差
