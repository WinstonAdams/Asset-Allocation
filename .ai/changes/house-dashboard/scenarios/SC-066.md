# SC-066: 五條觸發條件全部成立時顯示「可啟動購屋」

## 行為
- **GIVEN** 五條件如下（全部虛構值）：
  - 定錨（主觀）：已勾選
  - 收入（客觀）：家庭稅後月收 100,000 元 ≥ 收入門檻 90,000 元
  - 自備（客觀）：bucket 1,600,000 元 ≥ 目標 1,500,000 元，且一般用途活存＋定存 400,000 元 ≥ 現金地板 300,000 元
  - 月付（客觀）：目標總價正算月收占比 38.8% ≤ 月付上限比率 40%
  - 認知（主觀）：已勾選
- **WHEN** 檢視買房頁觸發條件檢核
- **THEN** 五條逐條顯示達成；達成計數 5/5；顯示「可啟動購屋」（BR-5）

## 邊界
- 「可啟動購屋」只在 5/5 全數成立時顯示；4/5 以下一律不顯示（見 SC-067 缺口清單）
