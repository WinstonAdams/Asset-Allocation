# SC-056: 個人化參數未設定（0）時呈現中性姿態，不誤判達標

## 行為
- **GIVEN** 收入門檻為 0（尚未設定）、家庭稅後月收 100,000 元
- **WHEN** 檢視五條觸發條件
- **THEN** 收入條件不視為達成；缺口清單對此條提示「尚未設定參數」（而非「未達標」，不得因 100,000 ≥ 0 誤判達標）

## 邊界
- 觸發計數的分母固定為 5：未設定的條件仍列在五條清單中、計為未達成（如兩條未設定＋兩條達成 → 顯示 2/5，不縮減分母）
- 目標總價為 0（尚未設定）時：bucket 進度不呈現進度百分比（目標 0 無法算比例）；自備條件與月付條件同樣計為未達成，缺口清單提示「尚未設定參數」（不得因目標 0 使 bucket ≥ 0、占比 0% ≤ 上限而誤判達標）
- 目標總價為 0 時，缺口與每年需累積速率皆不呈現
- 家庭稅後月收為 0（尚未設定）時：反推可負擔總價結果為 0 或呈現未設定，不得呈現為「可負擔 0 元」的誤導性結論
