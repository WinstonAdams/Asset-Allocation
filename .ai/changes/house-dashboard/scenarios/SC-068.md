# SC-068: 主觀觸發條件（定錨、認知）勾選狀態持久化

## 行為
- **GIVEN** 定錨與認知皆為未勾選（初始狀態）
- **WHEN** 使用者於買房頁勾選「定錨」
- **THEN** 勾選狀態立即存入資料庫；關閉並重新開啟應用程式後，「定錨」仍為勾選、「認知」仍為未勾選

## 邊界
- 取消勾選同樣持久化：勾選後再取消 → 重啟後為未勾選
- 從未操作過的主觀條件預設為未勾選（資料庫無紀錄視同未勾選）
- 主觀條件只有定錨與認知兩條；其餘三條（收入、自備、月付）為客觀自動判定，不提供手動勾選
