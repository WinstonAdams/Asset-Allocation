# SC-071: 總覽頁顯示買房進度摘要（bucket 進度% ＋ 觸發 x/5）

## 行為
- **GIVEN** bucket 進度 66.7%（bucket 1,000,000 元／目標 1,500,000 元）、觸發條件達成 3/5
- **WHEN** 開啟總覽頁
- **THEN** 顯示一條買房進度摘要：進度 66.7% ＋ 觸發 3/5，與既有協定等級摘要同層呈現

## 邊界
- 摘要口徑與買房獨立頁完全一致：同一時點兩頁顯示的進度%與 x/5 數字相同（同一計算來源，不得各算各的）
- 目標總價未設定（0）時：進度部分呈現未設定語意（無百分比）；觸發計數照常顯示（如 2/5，主觀勾選仍可成立）
- 摘要為唯讀概覽；勾選與參數修改仍在買房頁／設定頁進行
