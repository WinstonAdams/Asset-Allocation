# SC-059: 資料庫升級兩路徑：舊庫升級補一般用途、新庫直建即支援

## 行為
- **GIVEN** 一個本 Change 之前建立的既有資料庫，內含 3 筆持有項目（當時尚無用途概念）
- **WHEN** 新版應用程式首次啟動完成初始化
- **THEN** 3 筆既有項目全部自動視為用途「一般」；項目資料（名稱、分類、市值等）無任何遺失或變動

## 邊界
- 重複啟動安全：初始化重跑多次（如第 2、3 次啟動）不報錯、不重複變更、結果一致
- 全新資料庫首次啟動：直接支援用途標記與買房參數、主觀勾選的儲存，行為與升級後的舊庫一致
- 升級後舊庫的既有項目可正常編輯為「購屋」用途
