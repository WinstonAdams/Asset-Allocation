# house-dashboard：買房儀表板

## 背景動機

使用者已拍板將 asset-lab 升級定位為「個人財務決策平台」（見 `docs/ROADMAP.md`，2026-07-19 四項定案），本 Change 為序列第一步。

Workspace 私人文件 `人生策略/50-買房策略.md` 已寫定完整的購屋決策規則（可負擔性公式、自備款比率、五條觸發條件、目標購屋時點——時點屬私人參數，已定案存《人生策略/60-平台個人參數.md》），但目前只是靜態文件，每次檢視都要人手計算。本 Change 把這套規則編碼成儀表板：對照系統內的實際資產資料與可配置參數，即時呈現「現在買不買得起、離啟動購屋還差哪幾條」。純確定性數學，不需歷史報酬資料，也不做模擬。

**隱私邊界（全 Change 適用）**：程式碼、測試、文件不得含個人化數字；程式碼內建預設一律中性值（0 或虛構範例值），真實值由使用者經設定頁存入 DB（參照 ROADMAP §5 隱私護欄）。

## 目標

- 可負擔性試算：由稅後月收、驗算利率、貸款年限、月付上限比率反推可負擔總價；亦可輸入目標總價正算月付與月收占比
- 觸發條件檢核：`50-買房策略.md` §5 五條觸發條件逐條呈現達成狀態
- 自備款 bucket 進度：對照目標總價 × 自備比率，顯示目前累積、缺口，以及「缺口 ÷ 距目標購屋年份的剩餘年數 = 每年需累積」速率
- bucket 組成警示：bucket 含非活存/定存分類資產時顯示序列風險提示，距目標購屋年 ≤5 年時強化提示（只提示不強制，見 `docs/DECISIONS.md` D15）
- 所有政策參數可配置存 DB（新青安 2.0 定案後只改參數、不改程式）

## 範圍界定

### 本次做
- 新增「買房」獨立頁面（可負擔性試算、五條觸發條件檢核、bucket 進度與組成警示）
- 持有項目主檔新增「用途」標記（一般／購屋），新增與編輯介面同步支援；標記為純附加欄位，不影響既有分類、報酬與配置計算
- 主觀觸發條件（定錨、認知）的手動勾選狀態持久化存 DB
- 買房參數的 DB 存放與設定介面（沿用 protocol_thresholds 的可配置參數模式）
- 總覽頁補一條買房進度摘要（bucket 進度 % ＋ 觸發條件 x/5），與協定等級摘要同層

### 本次不做
- Monte Carlo／Bootstrap 模擬（Change 3）
- 完整 User Profile 參數層與政策檢查器（Change 2；本次只建買房所需的最小參數）
- 房貸攤還明細表、多方案比較（非策略文件要求）
- 任何行情或房價 API 介接
- 修改 `人生策略/50-買房策略.md` 本身（策略文件是輸入，不是本 repo 產物）

## 成功標準

- 自動化測試一律使用虛構參數值，驗證公式與判定邏輯正確（本息均攤、反推可負擔總價、觸發條件判定、速率計算）
- 使用者驗收時以《人生策略/60-平台個人參數.md》的「驗證錨點」節人工對照：填入真實參數後，可負擔總價應與策略文件既有結論同量級
- 五條觸發條件的達成判定與 `50-買房策略.md` §5 語義一致，全部成立才顯示「可啟動購屋」
- 參數修改後所有計算即時反映，非法參數（如比率 ≤0）存前被拒
- 既有 304 測試不退步，新行為皆有 SC 對應測試

## 核心業務能力

1. **可負擔性引擎**（純函式）：本息均攤月付計算、由月付上限反推貸款上限、貸款上限＋自備款合成可負擔總價
2. **觸發條件檢核**：主觀條件（定錨、認知，手動勾選存 DB）與客觀條件（收入門檻、bucket 達標、月付占比，由參數與資產資料自動判定）的混合檢核
3. **bucket 進度**：以持有項目「用途＝購屋」標記推導自備款累積，對照目標缺口與所需速率

## 業務規則快照

| # | 規則 | 邊界條件 | 例外 |
|---|------|----------|------|
| BR-1 | 可負擔判定：月付 ≤ 家庭稅後月收 × 月付上限比率（預設 35%），以驗算利率（預設 2.5%）與貸款年限（預設 30 年）計算本息均攤 | 寬限期不納入可負擔判定（以足額月付驗算） | 無 |
| BR-2 | 總自備資金 = 目標總價 × 自備比率（預設 33%，含頭期＋雜支＋裝潢） | 比率可配置，須 >0 且 <100 | 無 |
| BR-3 | bucket = 標記「用途＝購屋」的持有項目最新月度市值合計 | 標記項目尚無任何月度紀錄時以初始市值計；用途欄位預設「一般」 | 無 |
| BR-4 | bucket 達標 = bucket ≥ 目標總價 × 自備比率，且未標記購屋的活存＋定存合計 ≥ 現金地板參數（對應「動用後仍留預備金」；金額屬私人參數，程式碼預設中性值） | 現金地板本身永遠不計入 bucket | 無 |
| BR-5 | 五條觸發條件（定錨／收入／自備／月付／認知）全部成立才顯示「可啟動購屋」；任一不成立顯示缺口清單 | 定錨與認知為手動勾選存 DB；收入條件 = 家庭稅後月收 ≥ 門檻參數（換算口徑見 `docs/DECISIONS.md` D18，值屬私人參數） | 無 |
| BR-6 | 目標總價與目標購屋年份皆為可配置參數（值屬私人參數，使用者已定案存私人參數檔）；年份用於計算每年需累積速率 | 目標年份已過或等於當年時，速率顯示「已到目標年」不除以零 | 無 |
| BR-7 | 所有參數存 DB、存前驗證，非法值拒絕不落庫（沿用 protocol_thresholds 模式）；程式碼不內建任何個人化預設值 | — | 無 |
| BR-8 | bucket 含非活存/定存分類資產時顯示序列風險提示；距目標購屋年 ≤5 年時強化提示 | 只提示，不強制、不自動再平衡 | 無 |
| BR-9 | 用途標記為純附加欄位：本 Change 不改動既有分類、報酬、配置偏離計算（偏離排除規則屬 Change 2，見 `docs/DECISIONS.md` D14） | — | 無 |
