# SC-100: 負債只填應繳金額，淨投入固定為 0

## 行為
- **GIVEN** 項目「信用卡」（負債）在 2026-05 尚無紀錄
- **WHEN** 使用者在月度錄入頁只填應繳金額 30000 並存檔
- **THEN** 2026-05 紀錄落地：金額 30000、淨投入 0
- **AND** 錄入框只有「應繳金額」一欄，沒有淨投入欄
- **AND** 該月淨值 = 總資產 − 30000
- **WHEN** 使用者把 2026-05 應繳金額改成 28000 並存檔
- **THEN** 同一 (2026-05, 項目) 紀錄更新為 28000、淨投入維持 0，不新增重複列
- **WHEN** 使用者刪除該筆紀錄
- **THEN** 該 (2026-05, 項目) 紀錄被移除，不影響其他月份

## 邊界
- 各類貸款（例如「房貸」）適用同一規則
- 應繳金額留空時拒絕存檔並提示必填
- 負債本不計入報酬率，淨投入固定 0 不影響任何報酬計算
- 舊的負債紀錄若有非 0 手填淨投入，沒重存的維持原值；重存後淨投入變為 0
