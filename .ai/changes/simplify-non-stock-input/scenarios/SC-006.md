# SC-006: 新增/編輯/刪除某月單一項目紀錄

## 行為
- **GIVEN** 使用者在 2026-05 月度表單中操作某資產項目「活存」
- **WHEN** 新增一列：只填餘額 520000
- **THEN** 該 (2026-05, 項目) 紀錄被儲存，淨投入由系統依前期餘額自動推算（見 SC-092）
- **WHEN** 編輯該列餘額改為 530000
- **THEN** 同一 (2026-05, 項目) 紀錄被更新為 530000，不新增重複列
- **WHEN** 刪除該列
- **THEN** 該 (2026-05, 項目) 紀錄被移除

## 邊界
- 其他分類的項目以各自的欄位錄入（股票/ETF 見 SC-074、保險見 SC-095、負債見 SC-100），新增/編輯/刪除的行為相同
