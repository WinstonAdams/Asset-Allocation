# SC-097: 保險前一筆為舊方式紀錄時，前期累計保費以初始成本加總淨投入估算並標示

## 行為
- **GIVEN** 項目「儲蓄險」（分類：保險）初始成本 500000，本功能上線前以舊方式記錄了兩個月：2026-02 淨投入 20000、2026-03 淨投入 20000（皆未填累計保費）
- **WHEN** 使用者在 2026-04 第一次以新方式填累計已繳保費 560000、解約金 540000、領回 0
- **THEN** 前期累計保費以「初始成本 500000 ＋ 該月以前所有淨投入（20000＋20000）＝ 540000」估算
- **AND** 推算本月淨投入 = (560000 − 540000) − 0 = 20000
- **AND** 存檔前畫面標示前期累計保費 540000 是估算值，提醒使用者核對

## 邊界
- 舊紀錄之前若有手填的領回（負淨投入），估算會低估真正累計保費，因此需提醒使用者核對
- 之後的月份前一筆已是新方式紀錄，直接取其累計保費，不再標示估算
