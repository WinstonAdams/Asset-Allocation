# SC-103: 資金在項目間移動時，更新兩端數字即一出一進相抵，無需另做項目間轉移

## 行為
- **GIVEN** 「活存」2026-04 餘額 500000；「台積電」（台股/台股ETF）2026-04 總成本 300000
- **WHEN** 使用者在 2026-05 把 100000 從活存拿去買台積電，並更新兩端：活存餘額填 400000、台積電總成本填 400000
- **THEN** 「活存」2026-05 淨投入自動為 400000 − 500000 = −100000
- **AND** 「台積電」2026-05 淨投入推算為 (400000 − 300000) − 0 = +100000
- **AND** 整體一出一進相抵，總資產與整體報酬率不因資金移動而改變
- **WHEN**（另一情境）使用者賣出台積電實收 150000（總成本 400000 → 250000，已實現損益 0）並存入活存，活存餘額填 550000
- **THEN** 台積電端推算淨投入為 −150000，活存端自動為 +150000
- **AND** 月度錄入頁面上沒有「項目間轉移」功能，股票/ETF 欄位旁也沒有「需另做轉移」的提示

## 邊界
- 活存→定存同理：活存餘額少 50000（淨投入 −50000）、定存餘額多 50000（淨投入 +50000）
- 過去轉移留下的紀錄與淨投入照原樣保留，不回溯改動
