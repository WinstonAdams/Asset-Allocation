# SC-101: 負債金額欄在錄入框與本月紀錄表一律稱「應繳金額」

## 行為
- **GIVEN** 2026-06 已有紀錄：「活存」餘額 370000、「信用卡」（負債）應繳金額 30000、「房貸」（負債）金額空白未填
- **WHEN** 使用者在月度錄入頁選取負債項目「信用卡」
- **THEN** 錄入框的欄位標籤為「應繳金額」，並帶入既有值 30000
- **WHEN** 使用者選擇月份 2026-06 查看本月已存紀錄表
- **THEN** 資產列（「活存」）的金額顯示在「市值 / 餘額」欄，「應繳金額」欄留空
- **AND** 負債列（「信用卡」）的金額 30000 顯示在「應繳金額」欄，「市值 / 餘額」欄留空
- **AND** 「房貸」因金額空白，提醒文字為「本月應繳金額尚未填」（資產列維持「本月市值尚未填」）

## 邊界
- 信用卡與各類貸款一律稱「應繳金額」
- 淨值圖的「總負債」彙總線、匯出檔欄名不改名

## 決議
- 已確認（採推薦值）：淨值圖的「總負債」彙總線維持原名，只改單一負債的金額欄。
