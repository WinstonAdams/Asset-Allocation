# SC-090: 股票/ETF已實現損益與現金股利分開輸入，相加為原已實現收益合計

## 行為
- **GIVEN** 項目「日月光」（分類：台股/台股ETF）2026-05 總成本 200000，2026-06 全數賣出
- **WHEN** 使用者在 2026-06 輸入本月總成本 0、現值 0、本月已實現損益 100000、本月現金股利 2000
- **THEN** 系統以兩欄相加 100000 + 2000 = 102000 作為原本的已實現收益合計，代入既有推算公式
- **AND** 推算本月淨投入 = (0 − 200000) − (100000 + 2000) = −302000（總成本歸零，加上已實現損益與現金股利一併從淨投入中扣除）
- **AND** 存檔後該筆紀錄的已實現損益與現金股利分開落地保存，之後重新選取該項目與月份時各自被帶回（見 SC-088）

## 邊界
- 已實現損益可以為負（認列虧損），現金股利不可為負（照抄入帳通知，入帳金額不會是負的）
- 欄位旁不再顯示「需另做項目間轉移」的提示（項目間轉移功能已移除，見 SC-103）
