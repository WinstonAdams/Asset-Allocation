# SC-102: 資產項目未指定分類時無法錄入，提示先到設定頁指定分類

## 行為
- **GIVEN** 資產項目「舊匯入項目」分類留空（例如由匯入檔帶入）
- **WHEN** 使用者在月度錄入頁選取該項目
- **THEN** 畫面顯示錯誤，提示先到設定頁為該項目指定分類
- **AND** 不顯示任何錄入欄位，無法存檔，不產生任何月度紀錄

## 邊界
- 不可默默當成活存處理
- 為該項目指定分類（例如活存）後，即以該分類的方式錄入
