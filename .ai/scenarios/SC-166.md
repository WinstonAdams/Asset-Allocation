# SC-166: 減少動態偏好時畫面靜態

## 行為
- **GIVEN** 使用者的系統設定為減少動態
- **WHEN** 城市顯示或切換月份
- **THEN** 旗子靜止、不播放高度過渡動畫，建築直接呈現當月高度

## 邊界
- 一般情況下月份切換時高度平滑過渡；變為空地時高度降到 0 後不再繪製，反向則從 0 長出
- 以人工目視驗收

## 測試對映
- 預期：人工目視清單（無自動化測試）
