# SC-072: 家庭稅後月收尚未設定（0）時正算月付占比的呈現

## 行為
- **GIVEN** 家庭稅後月收為 0 元（尚未於設定頁填入，AD-7 個人化參數中性預設）
- **WHEN** 執行正算試算
- **THEN** 月付占比（income_share_pct）回傳 None；畫面顯示「尚未設定月收」而非誤導性的
  0% 或例外錯誤；月付、貸款金額、自備款等其餘欄位正常計算

## 邊界
- 月收未設定時，月付占比不可呈現為 0%（會被誤讀為「月付為 0」），也不可拋出例外中斷試算
- 連帶語義（供 t06 觸發條件檢核引用）：月付占比為 None 時，五條觸發條件中的「月付」
  條件視為未達成（fail-closed），與 SC-069（現金地板未設定時自備條件不視為達成）、
  SC-056（個人化參數未設定時呈現中性姿態、不誤判達標）的既定原則一致
