# SC-092: 活存/定存只填餘額，當月淨投入以本月餘額減前期餘額自動推算

## 行為
- **GIVEN** 項目「活存」（分類：活存）初始市值 300000，尚無任何月度紀錄
- **WHEN** 使用者在 2026-04 只填餘額 500000
- **THEN** 系統以初始市值 300000 作為前期餘額（尚無前一筆紀錄）
- **AND** 推算本月淨投入 = 500000 − 300000 = 200000
- **AND** 存檔前畫面顯示前期餘額 300000 與推算淨投入 200000 供使用者核對
- **AND** 存檔後 2026-04 紀錄落地：餘額 500000、淨投入 200000
- **WHEN** 使用者接著在 2026-05 只填餘額 600000
- **THEN** 系統以 2026-04 的餘額 500000 作為前期餘額，推算淨投入 = 600000 − 500000 = +100000
- **AND** 「活存」2026-05 的當月報酬為 0
- **WHEN** 使用者接著在 2026-06 只填餘額 450000
- **THEN** 推算淨投入 = 450000 − 600000 = −150000（餘額減少視為提領）

## 邊界
- 定存（分類：定存）適用同一規則，例如「一年期定存」2026-05 餘額 1000000、前期餘額 1000000，推算淨投入 0
- 利息、到期利息一律視為存入：活存 2026-05 餘額 600000 中若含 300 元利息，仍整額計入淨投入 +100000，報酬為 0（使用者接受）
- 出清或轉出全部時填餘額 0：前期餘額 600000 → 推算淨投入 −600000
- 項目只有初始市值未填（初始市值留空）且尚無紀錄時，前期餘額視為 0
