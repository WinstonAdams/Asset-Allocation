# SC-055: 非法買房參數存前被拒且不落庫

## 行為
- **GIVEN** 資料庫已存自備比率 30%
- **WHEN** 使用者於設定頁將自備比率改為 0（或 100、或 -5）並嘗試儲存
- **THEN** 儲存被拒並顯示錯誤訊息；資料庫中自備比率維持 30% 不變（非法值不落庫，BR-7）

## 錯誤
以下輸入皆須被拒（存前驗證，逐項）：
- 比率類（自備比率、月付上限比率）：0、100、-5、120 皆非法（合法域 0 < x < 100）
- 驗算利率：-0.5 非法（合法域 ≥ 0，0 為合法值）
- 貸款年限：0、-1 非法（合法域 > 0 的整數）
- 金額類（目標總價、家庭稅後月收、收入門檻、現金地板）：-1 非法（合法域 ≥ 0；0 合法＝未設定）
- 目標年份：-1 非法（合法域 ≥ 0；0 合法＝未設定）
