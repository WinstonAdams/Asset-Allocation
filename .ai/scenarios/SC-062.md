# SC-062: bucket 值 = 購屋標記項目的最新月度市值合計

## 行為
- **GIVEN** 主檔含 3 筆項目：「範例定存」（購屋，最新月市值 600,000 元）、「範例股票」（購屋，最新月市值 400,000 元）、「範例活存」（一般，最新月市值 500,000 元）
- **WHEN** 計算自備款 bucket
- **THEN** bucket = 600,000 + 400,000 = 1,000,000 元（僅計購屋標記項目；一般項目的 500,000 不計入，BR-3）

## 邊界
- 購屋標記項目尚無任何月度紀錄時，以其初始市值計：上例若再加一筆「範例新定存」（購屋、無月度紀錄、初始市值 200,000 元），bucket = 1,200,000 元（BR-3）
- 沒有任何購屋標記項目時，bucket = 0
- 購屋標記項目在最新月快照中市值為 0 時，以 0 計（不回退初始市值——初始市值僅用於「無任何月度紀錄」的情形）
